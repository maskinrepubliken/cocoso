# Trana: the crane icon

`public/3dicons/trana.webp` is our own icon, made to sit next to the
3dicons.co set (dynamic angle, color style). Everything here is generated
from `trana.py`, so the model can be adjusted and re-rendered.

- `trana.py`: builds the whole bird in Blender with bpy, sets up camera,
  lights and Cycles, renders a transparent PNG and saves `trana.blend`.
- `export.py`: trims the render, scales it to 320 px (longest side),
  writes the WebP, a 1024 px preview and the comparison sheet.
- `renders/`: one PNG per iteration, `v16-final.png` is the current icon (folded wings, standing, head turned).
- `trana.blend`: the scene as last rendered (regenerated by the script).

Re-render and re-export with a portable Blender 4.2 (no install needed):

    blender -b -P docs/design/trana/trana.py -- \
        --out "$PWD/docs/design/trana/renders/v10.png" --size 2048 \
        --samples 192 --blend "$PWD/docs/design/trana/trana.blend"
    python3 docs/design/trana/export.py docs/design/trana/renders/v10.png

For quick checks use `--size 768 --samples 48` (a few seconds on Apple
Silicon with Metal; the script falls back to CPU). Shape, pose, colours,
camera and lights are all named constants near the top of each builder in
`trana.py` (`SPINE`, `COL_*`, `build_wings`, `build_camera`, `build_lights`).
